## 基础实现修复

- 在途查询退出时，官方核心可能先释放业务对象，再等待执行线程结束。已在私有构建副本中调整关闭顺序，保留并记录全部三处生命周期补丁。官方原目录不变。
- 视频回调在复制前预留全局 64 MiB 载荷预算，取消和释放归还预算；限制每个回调的队列长度。
- Map 仅处理自身可枚举字符串键，正确保留特殊键；拒绝 float 溢出。
- 正常加载器拒绝测试探针库及旧 API 3 库；构建拒绝覆盖现有产物，验证依赖后转移完整输出目录。
- 官方源码归档按内容摘要校验，无需 Git 元数据；提供独立源码白名单、内容扫描、许可证归属、锁文件和实际安装测试。
